# Viewing GitHub Actions Status in Cursor

You can see GitHub Actions workflow status directly in Cursor! Here's how:

## Install GitHub Actions Extension

1. **Open Extensions in Cursor:**
   - Click the Extensions icon in the sidebar (or press `Ctrl+Shift+X` / `Cmd+Shift+X`)

2. **Search for "GitHub Actions":**
   - Look for the official **"GitHub Actions"** extension by GitHub
   - Install it

3. **Authenticate:**
   - After installing, you'll be prompted to sign in to GitHub
   - Grant permissions to access your repositories

## Features You'll Get

✅ **View workflow runs** directly in Cursor  
✅ **See status** (running, passed, failed) with colored indicators  
✅ **View logs** without leaving the editor  
✅ **Re-run workflows** from Cursor  
✅ **Syntax validation** for workflow files  
✅ **Autocomplete** for GitHub Actions workflows  

## Where to Find It

Once installed, you'll see:
- **Source Control** panel - Shows Actions status for your current branch
- **GitHub Actions** sidebar - Dedicated panel for workflow management
- **Status bar** - Shows current workflow status at bottom of editor

## Alternative: GitHub Pull Requests Extension

For even more GitHub integration, also install:
- **GitHub Pull Requests and Issues** extension
- This gives you PR reviews, issues, and Actions status all in one place

---

**Note:** Cursor is based on VS Code, so all VS Code extensions work! The GitHub Actions extension is officially maintained by GitHub.
